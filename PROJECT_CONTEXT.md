# Project Context

## Project
RGB-HSV Color Studio

## Course
Computer Graphics

## Assignment Goal
Build an interactive program that supports RGB and HSV color selection and two-way color conversion.

## Required Deliverables
- Source code
- Executable program
- Brief program description
- Runtime screenshots
- In-class demonstration

## Tech Stack
- Python
- Tkinter
- VS Code

## Core Features
- RGB color selection
- HSV color selection
- RGB to HSV conversion
- HSV to RGB conversion
- Live color preview

## Development Principles
- Keep the interface simple and easy to understand.
- Do not add unnecessary complexity.
- Core RGB-HSV conversion algorithms must be understandable and explainable.
- AI may assist with coding, but core course knowledge must be understood.

## Development Stages
- V0: Project setup
- V1: RGB controls and live preview
- V2: RGB to HSV conversion
- V3: HSV to RGB conversion
- V4: Interactive color picker
- V5: UI improvements and testing
- V6: Packaging, documentation, and final submission
